## Counter

A simple interactive counter application built using HTML, CSS and vanilla JavaScript.

This project is part of my frontend development learning journey, where I practise JavaScript fundamentals by building small interactive web applications.

## Technologies Used

• HTML
• CSS3
• JavaScript(vanilla JS)

## Features 

• Increase - increments the counter by 1
• decrease - decrement the counter by 1
• Reset - reset the counter to 0
• Updates the displayed number immediately without refreshing the page

## What I Learned

Through this project, I practised:

• Selecting HTML elements using `document.querySelector()`
• Handling button clicks using `addEventListener()`
• Declaring and updating varibles with let 
• Using increment (++) and decrement (--) operators
• Updating HTML content using `textContent`
• Understanding haw JavaScript responds to user interaction

## How It Works 

The counter starts at 0 and uses a variable called count to store its current value.

When the user clicks a button, JavaScript updates the variable and displays the new value on the page.

• Increase: count++
• Decrease: count-- 
• Reset: count = 0

The displayed value is updated using:

`counterValue.textContent = count;`
